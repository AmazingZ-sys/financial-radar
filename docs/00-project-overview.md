# Financial Radar 项目总览

设计基线：2026-11-02；状态：设计先行，按 `17-implementation-plan.md` 验收。

## 产品边界

金融雷达是单管理员起步、可扩展到多用户的信息监控平台。核心是尽早发现链上新协议和参与阶段变化，保存原始信息、证据、发现时刻和独立的机会/风险评分。提供宏观热点、行情、规则、通知和历史回放。禁止交易、签名、私钥管理，禁止将模拟数据或日度数据描述为实时行情。

## 两条用户路径

1. 热点：官方数据采集 → 标准事件/聚合 → 确定性规则 → 持久化通知 → Telegram 接受状态。
2. 机会：新协议/部署/铸造信号 → 项目时间线/指标 → 来源验证 → 两套独立评分 → 人工研究/观察。

## 交付物与运行模式

- Vue 3 控制台、Hono API、BullMQ Worker、PostgreSQL、Redis；API 和 Worker 独立镜像。
- `DATA_MODE=fixture`：明确标记的合成样本，经数据库与真实处理链验证，不产生投资回测结论。
- `DATA_MODE=live`：仅启用已实现且已配置来源；无密钥或无授权的数据返回未知/未配置；不自动回退样本冒充真实。
- Docker Compose 开发/生产，宿主 Nginx，GHCR 语义版本，Netlify 前端。
