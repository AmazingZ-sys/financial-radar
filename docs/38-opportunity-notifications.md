# 38 · 机会通知降噪

设计日期：2026-11-05。普通 ETH 新交易对、BRC20 部署和状态变化保存为观察事实，不因发现即外发。每项目冷却不能限制大量不同新币，机会分也不能代替来源和参与条件核验。

## 统一准入

- 原始建池、部署、mint 与链上快照只观察；旧 `includeRoutineEvents` 不再允许绕过链上发现过滤。行情快照仍可按明确规则选择。
- 链上项目的增长、流动性、成交量、启动和参与窗口信号，须来源已核验、置信度至少 0.8、机会分至少 65、独立风险分至多 60，并处于 EARLY_STAGE/ACTIVE、参与条件已核验且有非空条件说明，才能继续匹配用户规则。规则可进一步收紧；单纯高分不能放行。
- 结构化严重风险不受机会准入限制，继续匹配独立风险规则，不等待 AI。宏观/新闻与 X 研究提醒沿用自身规则，不把它们描述为已验证链上机会。
- 规则测试、创建通知和发送前复查共用判定。发送前读取当前规则及持久化事件；旧排队/重试消息不合格则 CANCELLED 并保存原因，不删除历史、不改写 SENT、不伪造已读。手动渠道测试保持独立。

## 当前线上规则

将已有宽泛示例规则收紧为已核验机会：置信度 80%、机会分至少 65、风险至多 60、仅已验证来源，仅保留关键参与/增长/流动性/启动信号，同项目冷却 24 小时。保留现有渠道；普通发现仍入库可查。实际配置和验证结果追加 acceptance.md；本地防护只有部署后才生效，不据本地测试声称生产队列已取消。
